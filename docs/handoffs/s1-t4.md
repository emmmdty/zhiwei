## 3. RLS 矩阵（表 × 角色 × context，实证）

| 表 | 角色/owner | relrowsecurity/force | context | 行为 |
| --- | --- | --- | --- | --- |

| organizations | zhiwei_app | t/t | org=org1 | 只见 org1 |
| workspaces | zhiwei_app | t/t | 仅 org | 见该 org 全部 workspaces（org 级 list 所需） |

| groups/workspace_memberships/group_members | zhiwei_app | t/t | org+ws 必须成对 | 仅该 org+ws；错配或仅 ws→0；跨 org INSERT→RLS error |

| principals/external_identities/auth_sessions/oidc_login_attempts/secret_envelopes | identity-global | f/f | 无 GUC 可读（zhiwei_identity） | 不套用租户 RLS（契约 9） |

## 4. Pool 泄漏证据（test_pool.py + 独立探针）

- 同一物理连接（pg_backend_pid 相等，pool_size=1/max_overflow=0）：事务 A 设 org1+ws1 → commit；
  下一事务 GUC 为空（`''`/NULL）、org1 数据 0 行；
- rollback 后同样清空；checkout 后无 context 看不到上一租户；
- 后续 org2 事务只见 org2；`zhiwei.workspace_id` 单设也被 RLS 全拒；
- `set_tenant_context` 在无活动事务时抛 RuntimeError（fail closed）。

## 5. IDOR / list / count / cursor 证据（test_idor.py，9 用例）

- 两 org 重叠名（'sales'/'platform'）+ 可猜固定 UUID：跨 org/workspace 单资源读统一 404、
  mutation 统一 403（API 层 ASGITransport 实证，写零落库）；
- body/path 自报 organization_id 不能覆盖 actor context（repo 层 TenantScopeError +
  API 403/404 双断言）；
- list/count/cursor：org_a 上下文对 org_b 数据恒 0 行、页数不泄露存在性；名称查询不跨 org 碰撞；
- 双层防线：RLS 剥离（migrator DROP POLICY + DISABLE）后 repository 谓词仍挡
  （get_group→None / TenantScopeError），try/finally 逐字还原 policy 并验证 catalog；
- memberships/workspace_memberships IDOR 同样阻断。

## 6. Audit 字段、digest、事务原子性证据（test_audit.py，11 用例）

- **字段**：v2 行存储并 digest 覆盖全部 17 项（org/ws、action、resource_type/id/version、
  actor_ref、effective_identity_ref、decision_id、policy_revision、decision_reason、
  result、request_id、trace_id、payload_digest、previous_event_digest、audit_schema_version）；
  actor 与 effective identity 分字段（delegation 形状也忠实存储并进入 digest）；
- **digest 版本分派**：v1 公式与 785cee0 逐字节一致（独立复算比对）；v1/v2 行同一链共存按版本验证；
- **篡改**：17 类篡改（含跨 scope、版本降级）逐列 SQL-UPDATE 后 `verify_audit_chain` 全部
  EventChainError，恢复后链重新完整可验证；
- **原子性**：mutation+audit+outbox 同事务提交（三行同现）；回滚三者同灭；
- **denied mutation**：`append_fail_closed_audit` 独立事务（tenant_session + 事务局部 GUC）
  落库拒绝记录，业务零写入；decision_id/revision 为 NULL（不伪造 OPA metadata）；
- **secret**：audit_events/outbox 全表扫描不含 token/cookie/authorization header 标记；
- **并发**：8 路并发 append 无分叉（advisory xact lock 0x41554454 + 唯一约束兜底），单 head。
