三类 metadata（`tests/integration/rls` 逐字段断言）：

| result | decision_id / policy_revision | decision_reason | 来源 |
| --- | --- | --- | --- |
| allowed | 真实决策，逐字保留（decision-allow-1/bundle-rev-1） | `allow:matrix` | 真实 OPA 决策 |
| denied（OPA deny） | 真实决策，逐字保留（decision-deny-1/bundle-rev-1） | `deny:default_deny:no_rule_matched` | 真实 OPA 决策 |
| denied（本地拒绝） | 双 NULL | `tenant_scope_mismatch` / `opa_unavailable` 等固定码 | PEP 本地 |
| failed（业务拒绝） | 双 NULL | `idempotency_conflict` 等固定码 | 业务状态 |

rollback 与幂等证据：bootstrap 审计写失败（DB 触发器注入）→ 500 + 四表零残留；
deny 路径审计写失败 → 500 + 业务零写入（mutation 绝不执行）；精确重放 → 200 原响应、
审计/outbox 计数不变；冲突 → 409 + failed 审计 + 业务零写入。

payload_digest 语义（独立复算实证）：allowed = `digest({resource_type, resource_id, resource_version})`；
denied/failed = `digest({request_id, resource_type, resource_id, action})`（Subagent A 用
`contracts.canonical.digest` 与裸 hashlib 双路径复算一致）。
