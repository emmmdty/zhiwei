## 2. 设计缺口处置（对照 docs/handoffs/s1-t5-design.md §1-§10）

- **端点矩阵（§1）**：User create/get by id/replace active/PATCH active；Group create/list/get/reconcile；其余显式 501（GET /Users list、DELETE、PATCH/DELETE /Groups、Bulk、Me、ServiceProviderConfig、ResourceTypes、Schemas、.search）。未注册 /scim/v2 路径 → FastAPI 404。
- **认证（§2 候选 A）**：复用 OIDC BFF session_actor（表现层包装转 SCIM 错误体，不造第三套 auth）；issuer = `ZHIWEI_OIDC_ISSUER` 组合期注入（唯一注入点 app.py），请求体禁止携带（extra=forbid）。
- **授权（§10）**：读写统一经 `api.policy_gate.authorize_mutation`（ORG/MANAGE，Rego 矩阵 org.manage）；allowed 读不写审计、denied 读写 denied 审计；不建第二套权限判定。
- **幂等/diff/事务（§4）**：重复 externalId → 409 uniqueness + failed 审计；reconcile diff 空 → changed=False 零写入；并发双 POST 一方 201 一方 409 + 事务整体回滚（败方零残留）。
- **disable（§5）**：走 `IdentityStore.set_principal_status` 双向；不删除历史 actor 引用；T2/T1 既有阻断/审计零改动。
- **schema/迁移（§3）**：User/Group 零 DDL；0009 仅 GRANT DELETE on group_members（downgrade REVOKE 可逆，RLS 语义不变）。
- **表现层（§8）**：SCIM 错误体 JSONResponse 直接返回（不依赖 app 级 handler）；路径 UUID 手工解析（避免 422）；If-Match/If-None-Match → 400；unknown 属性 extra=forbid → 400 invalidSyntax；meta.lastModified=created_at、meta.version 省略（§13 偏差登记）。
