## API 草图

```python
# src/zhiwei/config/settings.py
class DeploymentProfile(StrEnum):      # test | local_product | production_reference
class ReleaseMode(StrEnum):            # fixture_only | live

class Settings:                        # 冻结的 pydantic 模型
    profile: DeploymentProfile
    release_mode: ReleaseMode
    database_url: SecretStr | None
    object_store_root: Path | None
    model_api_key: SecretStr | None    # 来自 OPENAI_API_KEY
    model_base_url: str | None         # 来自 OPENAI_BASE_URL
    model_name: str | None             # 来自 OPENAI_MODEL
    live_model_calls_allowed: bool     # 属性

def load_settings(env: Mapping[str, str] | None = None) -> Settings: ...
```

环境变量：`ZHIWEI_PROFILE`、`ZHIWEI_RELEASE_MODE`、`ZHIWEI_DATABASE_URL`、
`ZHIWEI_OBJECT_STORE_ROOT`，以及**不带前缀**的 `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL`。

CLI 结构：`zhiwei dev doctor [--format text|json]`、`zhiwei db migrate [--timeout N]`、
`zhiwei db check [--format text|json] [--timeout N]`。

`dev doctor --format json` 的 stdout 必须是**纯 JSON**（能直接管进 `jq`），形如：

```json
{
  "profile": "test",
  "release_mode": "fixture_only",
  "live_model_calls_allowed": false,
  "checks": {
    "database":        {"status": "not_configured", "detail": "..."},
    "object_store":    {"status": "not_configured", "detail": "..."},
    "schema_revision": {"status": "unknown", "detail": "..."}
  }
}
```

任一 check 的 `status` 不是 `"ok"` 时退出码非零。

## 四条容易做错的地方

1. **不读 `.env`。** `load_settings({})` 传空 mapping 时结果必须是全空配置，哪怕 CWD 下就有
   `.env`。不要用 `pydantic_settings.BaseSettings` 的 `env_file`，也不要 `load_dotenv()`。
   显式传入的 mapping 是唯一来源，**不与 `os.environ` 合并**。
2. **`dev doctor` 不得发起任何网络连接。** 测试把 `socket.connect` 打了桩，连一次就红。
   DB 检查在这个 Task 里只做"配没配、DSN 能不能解析"，不实际连库。
3. **不得抛裸 traceback。** 配置错误、连不上库都要转成一行可读信息 + 非零退出码。
   测试断言输出里不含 `Traceback (most recent call last)`。
4. **不得回显凭据。** 错误信息、doctor 输出、`repr(settings)` 里都不能出现 API key 或 DSN 密码。
