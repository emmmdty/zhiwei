# S7 Memory System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add governed user, team and Case memory with provenance, candidate confirmation, temporal conflicts, scoped retrieval and complete revocation/deletion.

**Architecture:** Working memory remains canonical Run state. Long-term MemoryRecords are versioned PostgreSQL facts with derived indexes; write/read policies are explicit and Context Compiler consumes only authorized confirmed/candidate states allowed by profile.

**Tech Stack:** PostgreSQL/RLS, OpenSearch or shared retrieval ports, Pydantic, OPA, React, Pytest/Hypothesis, external LongMemEval/LoCoMo adapters where licensing permits.
